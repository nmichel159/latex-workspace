# Theoretical Computer Science (TCS)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | mathematical study of computation motivated by computing; three sections: *Algorithms, automata, complexity and games*; *Logic, semantics and theory of programming*; *Natural Computing* (theory of evolutionary computing, neural networks, molecular and quantum computing); also "advanced introductions" |
| Type, publisher | journal; Elsevier |
| Submission system | <https://submit.elsevier.com/TCS> |
| LaTeX | Elsevier template encouraged; the guide links [els-cas-templates.zip](https://assets.ctfassets.net/o78em1y1w4i4/5uFmLZJTPDMAUjFnHRpjj8/6f19a979146eb93263763d87a894ab0d/els-cas-templates.zip); `elsarticle` also offered ([LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions)) |
| Citation style | numbered in square brackets |
| Limits | abstract at most 250 words; 1-7 keywords; highlights encouraged; no page limit stated |
| Anonymity | single-anonymised; at least two reviewers |
| Supplementary, appendix | Elsevier standard: supplementary files with the manuscript |
| Source files | editable `.tex`; a PDF is not a source file |
| Preprints | allowed, not prior publication |
| OA model, APC | subscription with optional open access: APC USD 3190 (excl. tax), licence CC BY, CC BY-NC or CC BY-NC-ND (guide and OA page re-opened 2026-10-08); open archive after 48 months; accepted-manuscript repository embargo 24 months |
| AI policy | Elsevier: [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08) |
| Review time | not stated |
| Editorial office | tcseditorialoffice@elsevier.com (from the guide) |
| Fit | Min Cut-Path complexity and algorithms (first section); theory of evolutionary or LLM-guided search (Natural Computing section) |

Sources: [guide for authors](https://www.sciencedirect.com/journal/theoretical-computer-science/publish/guide-for-authors),
