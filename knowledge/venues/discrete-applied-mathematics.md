| Field | Value |
|---|---|
| Scope | algorithmic and applicable discrete mathematics, and combinatorics applied to informatics and other sciences |
| Type, publisher | journal; Elsevier |
| Article types | *Contribution* (full article, more than 10 pages); *Note* (self-contained, at most 10 pages); *Communication* (short new result sent directly to a chosen editorial-board member, who reviews it and forwards the final paper); *Perspectives* (surveys); *Erratum* |
| Submission system | Editorial Manager: <https://www.editorialmanager.com/dam/default.aspx> |
| LaTeX | official template: Elsevier CAS bundle 2.4, [els-cas-templates.zip](https://assets.ctfassets.net/o78em1y1w4i4/5uFmLZJTPDMAUjFnHRpjj8/6f19a979146eb93263763d87a894ab0d/els-cas-templates.zip), linked as "LaTeX template" from the guide ("We encourage you use our LaTeX template"); in the workspace `templates/els-cas/` (packager `-Template els-cas`), class `cas-sc` (single column; `\ProvidesClass`: `cas-sc 2024/05/04, 2.4`), wrapper written from `cas-sc-template.tex`; class quirks: [template-porting.md](../writing/template-porting.md) §6.3. `elsarticle` ([zip](https://assets.ctfassets.net/o78em1y1w4i4/4MpsJHO0MOJ2xZuwGTAbOZ/7bc64af36477c5d6cfce335a1f872363/elsarticle.zip), `templates/elsarticle/`) is Elsevier's general class ([LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions)), not the one the DAM guide links |
| Citation style | any consistent style at submission, journal style applied at proof; numbers in square brackets, and the guide says the reference list is "arranged alphabetically and then numbered" (unlike IPL and TCS). Verified 2026-10-08 with article 1: `cas-model2-names.bst` (shipped in the CAS bundle; the `.bst` sorts by author) with `\usepackage[numbers]{natbib}` (the template's own alternative line; `sort&compress` added) prints labels [1]-[12] in alphabetical order of the first author's surname and the DOIs (`doi:10...`); BibTeX 0 warnings. The template's default line `\usepackage[authoryear,longnamesfirst]{natbib}` would print author-year citations, which DAM does not use. `elsarticle-num.bst` numbers by order of citation, so it does not give the DAM order |
| Abstract | guide, section "Abstract": concise and factual; states the purpose, outlines the basic procedures, includes the main findings and the principal conclusions, emphasises what is new; stands alone; no references (if essential, author and year); non-standard abbreviations defined at first mention |
| Limits | abstract at most 250 words, stand-alone, no references; 1-7 keywords in English, avoid multi-word keywords with "and" or "of"; highlights encouraged (3-5 bullets, at most 85 characters each including spaces, a separate editable file with "highlights" in the file name); length decides Note vs Contribution |
| Title page | concise title (no abbreviations or formulae where possible); given and family names; affiliations marked by lower-case superscript letters, each with its full name and postal address including the country; one corresponding author, whose e-mail address is on the title page and is published; present address as a footnote with an Arabic numeral |
| Anonymity | single-anonymised; at least one reviewer |
| Supplementary, appendix | supplementary files submitted together with the manuscript and cited in the text |
| Source files | editable `.tex` required ("A PDF is not an acceptable source file"). Editorial Manager (Elsevier LaTeX instructions, FAQ "Can I use subfolders in my TeX submission files?"): "No. LaTeX submissions containing subfolders cannot be processed by EM"; all files at one folder level, so package with `-Flat`. Item types: Manuscript for `.tex`, `.bbl`, `.bst`, `.sty`, `.bib` (the restricted-PDF section of the same page also lists `.cls`, the FAQ paragraph omits it), Figure for images; EM compiles the sources and returns only an error log when the build fails. The CAS class reads `thumbnails/cas-email.jpeg` for `\ead` unless its key `nologo` is set (set in the wrapper: [template-porting.md](../writing/template-porting.md) §6.3) |
| Figures | also supplied as separate files; vector drawings as EPS or PDF; bitmapped line drawings at least 1000 dpi; guide, section "Figures, images and other artwork": cite every image in the text, number the images in the order they appear, one image per file with a logical file name (for example Figure_1, Figure_2), no multiple images or graphs combined into one file (section "Do not submit"; exception: images meant to be compared); section "Captions": every image has a caption made of a brief title (not shown on the image) and a description of the image, with every symbol and abbreviation explained |
| Math | guide, section "Math formulae": equations as editable text, not images; simple formulae in line with the text where possible; the solidus (X/Y) instead of a horizontal line for small fractional terms; variables in italics; powers of e written with exp; displayed equations numbered consecutively in the order they are referred to in the text |
| Tables | guide, section "Tables": editable text, not images; placed next to the relevant text or on separate pages at the end; every table cited in the text, numbered consecutively in order of appearance, with a caption; table notes below the body; no vertical rules and no shading in cells; data not duplicated elsewhere in the article |
| Statements | competing interests: the declarations tool (form) is always completed, "I have nothing to declare" when none; funding: list the funders ("Funding: This work was supported by ... [grant number ...]"), or the recommended sentence "This research did not receive any specific grant from funding agencies in the public, commercial, or not-for-profit sectors."; acknowledgements in a separate section directly before the reference list, nowhere else; research data: Option C (deposit and cite the data, or state why they cannot be shared); AI declaration: see *AI policy* |
| References | every reference must correspond to a real, existing source; DOIs where available; the guide asks for journal names abbreviated according to the List of Title Word Abbreviations (LTWA), while the journal reference style is applied at proof |
| Preprints | allowed, not prior publication; optional free SSRN posting at submission |
| OA model, APC | subscription with optional open access: APC USD 3460 (excl. tax), licence CC BY, CC BY-NC or CC BY-NC-ND (guide and OA page re-opened 2026-10-08); open archive: free to read 48 months after publication; accepted-manuscript repository embargo 24 months |
| AI policy | Elsevier ([submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08)). Guide, section "Declaration of generative AI use": AI use in manuscript preparation is declared at first submission by a statement at the end of the manuscript, in a new section before the reference list, which appears in the published article (the acknowledgements must stay directly before the reference list, so the declaration goes before the acknowledgements section); section title "Declaration of generative AI and AI-assisted technologies in the manuscript preparation process"; statement "During the preparation of this work the author(s) used [NAME OF TOOL / SERVICE] in order to [REASON]. After using this tool/service, the author(s) reviewed and edited the content as needed and take(s) full responsibility for the content of the published article."; basic tools that check grammar, spelling and references are exempt; nothing to disclose, no statement. AI tools are never listed or cited as authors |
| Review time | not stated |
