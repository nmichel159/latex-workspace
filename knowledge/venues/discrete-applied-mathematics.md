# Discrete Applied Mathematics (DAM)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | algorithmic and applicable discrete mathematics, and combinatorics applied to informatics and other sciences |
| Type, publisher | journal; Elsevier |
| Article types | *Contribution* (full article, more than 10 pages); *Note* (self-contained, at most 10 pages); *Communication* (short new result sent directly to a chosen editorial-board member, who reviews it and forwards the final paper); *Perspectives* (surveys); *Erratum* |
| Submission system | Editorial Manager: <https://www.editorialmanager.com/dam/default.aspx> |
| LaTeX | Elsevier template encouraged; the guide links [els-cas-templates.zip](https://assets.ctfassets.net/o78em1y1w4i4/5uFmLZJTPDMAUjFnHRpjj8/6f19a979146eb93263763d87a894ab0d/els-cas-templates.zip); `elsarticle` ([zip](https://assets.ctfassets.net/o78em1y1w4i4/4MpsJHO0MOJ2xZuwGTAbOZ/7bc64af36477c5d6cfce335a1f872363/elsarticle.zip)) is Elsevier's general class ([LaTeX instructions](https://www.elsevier.com/researcher/author/policies-and-guidelines/latex-instructions)) |
| Citation style | any consistent style at submission, journal style applied at proof; numbers in square brackets, and unlike IPL and TCS the guide says the reference list is "arranged alphabetically and then numbered" (guide re-opened 2026-10-08); `elsarticle-num.bst` is the numbered style Elsevier names, but it numbers by order of citation, so which `.bst` gives alphabetical-then-numbered order is TODO(verify) |
| Limits | abstract at most 250 words; 1-7 keywords; highlights encouraged (3-5 bullets, at most 85 characters each, separate file); length decides Note vs Contribution |
| Anonymity | single-anonymised; at least one reviewer |
| Supplementary, appendix | supplementary files submitted together with the manuscript and cited in the text |
| Source files | editable `.tex` required ("A PDF is not an acceptable source file"); Editorial Manager: all files in one folder (sub-folders break the build); `.bbl`, `.bst`, `.cls` uploaded as Manuscript items |
| Statements | competing-interest declarations tool always completed; funding sources; AI declaration |
| References | every reference must correspond to a real, existing source; DOIs where available |
| Preprints | allowed, not prior publication; optional free SSRN posting at submission |
| OA model, APC | subscription with optional open access: APC USD 3460 (excl. tax), licence CC BY, CC BY-NC or CC BY-NC-ND (guide and OA page re-opened 2026-10-08); open archive: free to read 48 months after publication; accepted-manuscript repository embargo 24 months |
| AI policy | Elsevier, declaration at submission: [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08) |
| Review time | not stated |
| Fit | Min Cut-Path (graph algorithms, complexity, random graphs); a single result of at most 10 pages matches the Note type |

Sources: [guide for authors](https://www.sciencedirect.com/journal/discrete-applied-mathematics/publish/guide-for-authors),
