# INFORMS Journal on Computing (IJOC)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | operations research and computing: original papers on theories, methods, experiments, systems and applications; also surveys, tutorials and papers describing software tools. Authors choose one of ten areas and one area editor |
| Type, publisher | journal; INFORMS |
| Submission system | ScholarOne Manuscripts, linked from the [submission guidelines](https://pubsonline.informs.org/page/ijoc/submission-guidelines); six steps (type, title and abstract; files; three to five keywords; authors with ORCID; cover letter and ethics certifications; review and submit). The system merges the uploaded files into one PDF for review |
| LaTeX | INFORMS style files, one zip per journal: <https://pubsonline.informs.org/authorportal/latex-style-files> (journal template, style file, BibTeX style, PDF documentation including `Style-Instructions.pdf`); the IJOC template file is `JOC-template.tex`. Class `informs4` with option `ijoc`: seen only in a third-party copy of the instructions ([MIT Sloan](https://mitsloan.mit.edu/sites/default/files/2025-08/Style-Instructions.pdf)), TODO(verify) after downloading the zip. The Overleaf copy of the IJOC template uses the older class `informs3` (2010): do not use it. Templates are not required for the first submission but strongly encouraged ([templates page](https://pubsonline.informs.org/authorportal/manuscript-templates-and-formatting-resources), updated 2026-09-01) |
| Citation style | author-year, list sorted alphabetically: (Norman 1977) or Norman (1977); examples on the [reference style page](https://pubsonline.informs.org/authorportal/reference-style-and-citation-examples); `.bst` is in the zip, name TODO(verify) |
| Limits | single column, 1.5 line spacing, 12 pt, 1 inch margins; at most 25 pages including abstract, references, tables and figures, plus up to 10 pages of appendices (an online supplement if longer than 2 pages); no footnotes; abstract at most 300 words, non-technical, no formulas, in the order questions, method and results, importance; 3-5 keywords; exceptions only after agreement with the area editor (stated in the cover letter) |
| Anonymity | single-blind: reviewers see the authors, so the title page carries all names and institutions. The generic INFORMS ethics page speaks of double-anonymous review; its text is journal-selectable, so follow the IJOC page and TODO(verify) at submission |
| Supplementary, appendix | online supplements (appendixes, data, most proofs, long tables, long literature reviews) are uploaded as separate files marked as supplemental material. Data and code of accepted papers go to the GitHub organization [INFORMSJoC](https://github.com/INFORMSJoC), outside the page count. [Data policy](https://pubsonline.informs.org/page/ijoc/datapolicy), [software policy](https://pubsonline.informs.org/page/ijoc/softwarepolicy): for papers whose main contribution is computational experiments, software with instructions and data to reproduce the results must be released as a condition of final acceptance |
| Source files | review: a PDF of the main document, sources optional. After acceptance (upload within 14 days): source file (LaTeX or Word), a PDF made by the author, figures as PostScript or PDF, online supplements in final form, signed copyright form and the Editorial Checklist. Revision: include a response-to-reviewers file and mark it "Supplemental File for Review" |
| Cover letter | required for new submissions: why IJOC is the right outlet (name a few IJOC papers on the topic), why this area; read by the editors, not by reviewers; funding is stated there. Conference versions: disclose in the cover letter, see proceedings policy below |
| Prior publication | a refereed proceedings paper is acceptable if the journal version extends it in substantial and meaningful ways, cites it, explains the extension, and comes with the original paper, a one-page summary of the extensions and a version with the unchanged portions highlighted ([proceedings policy](https://pubsonline.informs.org/page/ijoc/proceedingspolicy)). A rejected paper may not be resubmitted without written permission of the area editor or editor-in-chief |
| ORCID | required for the submitting author; INFORMS requires an ORCID for all authors of published articles; CRediT contributor roles are collected at submission |
| OA, fees | subscription route with copyright transfer to INFORMS; INFORMS Open Option: US$3,150 per article, publication license instead of copyright transfer ([Open Option](https://pubsonline.informs.org/authorportal/INFORMS-open-option)) |
| Self-archiving | the author accepted manuscript may be posted at once without embargo on personal sites, repositories and scholarly networks, with the DOI; the publisher's version only under the Open Option ([posting](https://pubsonline.informs.org/authorportal/author-posting-and-sharing)). Posting a preprint before submission is not addressed on the pages read: TODO(verify) |
| AI policy | the IJOC page is a reviewers-and-editors policy (August 2023): no manuscript, report or letter into a generative-AI tool. Authors: AI tools allowed, never as authors, authors responsible, submission declares that AI content was reviewed and verified; no disclosure place or format is stated ([ethics guidelines](https://pubsonline.informs.org/authorportal/guidelines-for-ethical-behavior-in-publishing), updated 2025-05-28). Policy row: [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08) |
| Review time | official statement: referee reports reach the associate editor within two months on average; appeals only for significant technical errors, one to eight weeks after the decision |
| Fit | LLM-based optimization methods with a full experimental study and released code; algorithm-engineering papers on combinatorial problems |

Sources: [submission guidelines](https://pubsonline.informs.org/page/ijoc/submission-guidelines),
