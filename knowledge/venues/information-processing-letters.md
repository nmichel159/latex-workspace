# Information Processing Letters (IPL)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | short, focused contributions on fundamental aspects of information processing and computing, mainly theoretical computer science; broad-interest experimental papers considered |
| Type, publisher | journal; Elsevier |
| Submission system | <https://submit.elsevier.com/IPL> |
| LaTeX | Elsevier template encouraged; the guide links [els-cas-templates.zip](https://assets.ctfassets.net/o78em1y1w4i4/5uFmLZJTPDMAUjFnHRpjj8/6f19a979146eb93263763d87a894ab0d/els-cas-templates.zip) |
| Citation style | numbered in square brackets |
| Limits | generally **nine printed pages**; abstract at most 250 words; 1-7 keywords; **highlights required** |
| Anonymity | single-anonymised; at least two reviewers |
| Source files | editable `.tex`; a PDF is not a source file |
| Preprints | allowed, not prior publication |
| OA model, APC | subscription with optional open access: APC USD 2880 (excl. tax), licence CC BY, CC BY-NC or CC BY-NC-ND (guide and OA page re-opened 2026-10-08; journal still published by Elsevier and open for submissions at <https://submit.elsevier.com/IPL>); accepted-manuscript repository embargo 24 months |
| AI policy | Elsevier: [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08) |
| Review time | not stated |
| Fit | one self-contained result with a short proof, e.g. a single Min Cut-Path theorem |

Sources: [guide for authors](https://www.sciencedirect.com/journal/information-processing-letters/publish/guide-for-authors),
[open access](https://www.sciencedirect.com/journal/information-processing-letters/publish/open-access-options).
