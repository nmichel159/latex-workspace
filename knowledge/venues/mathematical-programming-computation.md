# Mathematical Programming Computation (MPC)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | computational optimisation: new or improved computational techniques, software and data with demonstrated performance; heuristic and certified methods both considered |
| Type, publisher | journal; Springer (Springer Nature); submission link points to the Mathematical Optimization Society site |
| Submission system | via <https://mathprogramming.org/> (link on the guidelines page) |
| LaTeX | `svjour3` with option `smallextended` ([zip](https://media.springer.com/full/springer-instructions-for-authors-assets/zip/468198_LaTeX_DL_468198_240419.zip)); do not change page size or margins, do not load `geometry` |
| Citation style | numbered, square brackets; ISSN LTWA abbreviations |
| Limits | abstract 150-250 words; 4-6 keywords; MSC codes; no page limit stated |
| Anonymity | reviewers, technical editor and associate editor are anonymous; author anonymity not required (single-anonymous), TODO(verify) |
| Software and data | **required** unless the board grants an exception; software preferably as source code; a technical editor checks code quality, usability and qualitative reproducibility of the claimed results |
| Review | two referees plus one technical editor; the journal evaluates manuscript and software together |
| Statements | **Statements and Declarations** after the references (funding, competing interests and others); missing statements mean return as incomplete |
| OA model, APC | hybrid; subscription route free; open access APC GBP 2290 / USD 3390 / EUR 2590 (plus VAT); CC BY or CC BY-NC-ND 4.0 |
| AI policy | Springer journal text (Methods section; AI-assisted copy editing exempt); declare anyway, see [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08). For LLM-based solvers the LLM is part of the software under review: report model, version and prompts ([experiments-reporting.md](../writing/experiments-reporting.md)) |
| Review time | not stated |
| Fit | computational studies of LLM-driven optimisation or of exact Min Cut-Path solvers, provided the code is released |
