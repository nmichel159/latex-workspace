# IEEE Transactions on Evolutionary Computation (TEVC)

Checked 2026-10-08. Re-open every URL below before submitting.

| Field | Value |
|---|---|
| Scope | archival original papers on evolutionary computation and related areas: nature-inspired algorithms, population-based methods, optimization where selection and variation are integral, hybrids of these paradigms; purely theoretical papers and application papers with general insights are both considered |
| Type, publisher | journal; IEEE Computational Intelligence Society; six issues a year; article types: regular paper, letter (normally at most 6 pages), survey |
| Submission system | IEEE Author Portal: <https://ieee.atyponrex.com/journal/TEVC-IEEE>. The same page sends the final source files to ScholarOne: <https://mc.manuscriptcentral.com/tevc-ieee> |
| LaTeX | IEEE two-column format, class `IEEEtran` (CTAN 1.8b, maintainer Michael Shell); modes `journal`, `peerreview` among others ([HOWTO](https://ftp.fi.muni.cz/pub/tex/CTAN/macros/latex/contrib/IEEEtran/IEEEtran_HOWTO.pdf)); download via the [IEEE Template Selector](https://template-selector.ieee.org/). Which mode the journal expects for the anonymous review copy: TODO(verify). Not installed in the workspace MiKTeX: ship the class in the project (see [template-porting.md](../writing/template-porting.md)) |
| Citation style | numbered, IEEE style (the page asks for references "in IEEE style"); BibTeX style comes with the `IEEEtran` package, file name TODO(verify) |
| Limits | regular paper 10 pages, survey 15, letter 6; pages beyond these carry a mandatory charge (see OA, fees); maximum 15 / 21 / 9 pages; supplementary material not counted. Abstract 100-200 words without abbreviations, acronyms, footnotes, formulas or references; 2-5 keywords; title at most 15 words and without acronyms; font not below 10 pt |
| Anonymity | double-anonymous: no author names or affiliations in the manuscript; at least two independent reviewers. Acknowledgments may list only sponsors and named individuals, none addressed to anonymous reviewers or editors |
| Supplementary, appendix | a graphical abstract is encouraged and goes in as supplemental material, which is reviewed like any other; other supplementary rules: TODO(verify) |
| Source files | final stage: all text and graphics sources to ScholarOne; `.tiff`, `.eps`, `.ps` preferred for figures, all graphic types accepted |
| Prior publication | work must not be published or under review elsewhere (say so in "Comments to Editor-in-Chief"); earlier conference papers and book chapters only if enhanced significantly |
| ORCID | required for every author to submit a manuscript or review a proof |
| OA, fees | hybrid. Open access APC US$2800 for articles submitted in 2026; 5% discount for IEEE members, 20% for society members, none for students. Page charge US$110 per printed page, voluntary. Mandatory over-length charge US$200 per page beyond 10 / 15 / 6 pages. Copyright transfer to IEEE for the traditional route |
| Preprints | arXiv posting allowed; every posted version after submission carries the IEEE copyright notice; after publication replace it with the citation and DOI, or with the accepted version and DOI |
| AI policy | the journal page: disclose AI-generated text in the acknowledgments and cite the AI system in the sections that use it. Policy row: [submission.md](../writing/submission.md#11-policy-table-checked-2026-10-08) |
| Review time | not stated; the associate editor recommends after three reviews (two for letters) |
| Fit | LLM-guided evolutionary search, evolutionary algorithm design with general insight; not for pure graph-theoretic results |
